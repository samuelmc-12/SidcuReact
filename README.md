## Descripción del proyecto

**SIDCU (Simulador de Carreras Universitarias)** es una plataforma web que busca facilitar el proceso de orientación vocacional de estudiantes de secundaria y personas interesadas en iniciar su formación profesional.

A través de diferentes herramientas interactivas, los usuarios pueden conocer distintas carreras universitarias, identificar sus intereses y habilidades, comparar opciones académicas y consultar información sobre instituciones de educación superior.

El objetivo principal es brindar una experiencia sencilla e intuitiva que permita explorar diferentes alternativas educativas y contribuir a una elección profesional más informada.

## Características principales

- **Exploración de carreras:** catálogo de programas académicos con información sobre duración, costos, salarios y oportunidades laborales.
- **Orientación vocacional:** pruebas interactivas para identificar intereses, habilidades y afinidades profesionales.
- **Comparador de carreras:** herramienta para analizar y comparar diferentes opciones académicas.
- **Información universitaria:** consulta de instituciones de educación superior, ubicación y programas disponibles.
- **Gestión de usuarios:** registro e inicio de sesión para acceder a las funcionalidades de la plataforma.
- **Interfaz interactiva:** diseño intuitivo y adaptable para facilitar la navegación.

## Requisitos previos

Para ejecutar el proyecto localmente se recomienda contar con:

- Node.js y npm.
- Java JDK compatible con la versión del proyecto.
- Maven.
- Un navegador web moderno.
- Un entorno de desarrollo como Visual Studio Code o IntelliJ IDEA.

## Instalación y ejecución

### 1. Clonar el repositorio del frontend

```bash
git clone <URL_DEL_REPOSITORIO_FRONTEND>
```

### 2. Ingresar a la carpeta del proyecto

```bash
cd SIDCU
```

### 3. Instalar las dependencias

```bash
npm install
```

### 4. Ejecutar el frontend

```bash
npm run dev
```

La aplicación estará disponible en la dirección local que indique Vite en la terminal.

### 5. Obtener el backend

```bash
git clone https://github.com/alejandr0407/sidcu-backend.git
```

Para conocer las instrucciones específicas de configuración y ejecución del servidor, consulta el README del repositorio del backend.

## Objetivo del proyecto

SIDCU nace con el propósito de apoyar a los estudiantes en uno de los momentos más importantes de su vida académica: la elección de su futuro profesional.

Mediante herramientas tecnológicas, información académica y recursos de orientación vocacional, el proyecto busca acercar a los jóvenes a diferentes oportunidades de educación superior.
